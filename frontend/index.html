WHY THIS IS NOT ANOTHER CHATBOT

Most drug-interaction tools ask a language model to remember. This one asks a theorem prover to check.

Typical LLM approach

A model is asked "is X safe with Y" and answers from pattern-matched training data. It can be confidently wrong, miss a combination it wasn't trained on, or contradict itself between two phrasings of the same question.

"Combining these is generally considered low-risk, though you should check with a doctor."
This system

A patient's facts are asserted into a formal ontology. HermiT performs subsumption classification and either derives a named risk class — or proves the ontology inconsistent. The LLM rephrases the result; it cannot alter it.

⊢ P1 ∈ SerotoninSyndromeRiskPatient // derived, not guessed
ARCHITECTURE, LAYER BY LAYER

Six layers. Each one proof-bearing until the very last, translation-only step.

1
OWL Ontology
12 drug categories, properties like takesMedication and inhibits, and six risk classes defined as DL restrictions — e.g. SerotoninSyndromeRiskPatient ≡ Patient ⊓ ∃takesMedication.MAOI ⊓ ∃takesMedication.SSRI. No drug pair is ever hardcoded; risk emerges from category membership.
2
HermiT Reasoner via Owlready2
A real Description Logic reasoner performs subsumption classification: given a patient's asserted facts, it derives which risk classes apply, purely from logic — no code tells it the answer.
3
SWRL Property-Chain Rule
CYP3A4 toxicity can't be expressed as plain class intersection — it depends on which specific enzyme is shared between an inhibitor and a substrate. A Horn-rule extension joins two separate facts on top of the DL restrictions.
4
Inconsistency Detection
A pregnant patient on Warfarin isn't flagged "risky" — it makes the ontology logically unsatisfiable (ForbiddenPregnancyRegimen ≡ owl:Nothing). HermiT proves no valid model can satisfy the given facts.
5
Explanation Layer
Walks back from an inferred class to the exact drugs, categories, and axiom that produced it — a traceable path, not a black box.
6
LLM Layer translation only
Two narrow jobs: extract drug names and intent from free text, and rephrase the ontology's own explanation for readability — under a prompt that forbids adding or softening any claim. Every call has a tested fallback.
