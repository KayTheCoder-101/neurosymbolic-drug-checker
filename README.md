# Neurosymbolic Drug-Interaction Checker

LLM + OWL ontology hybrid system. All factual reasoning and consistency-checking
happens in an OWL ontology via HermiT (through Owlready2). The LLM only handles
NL understanding and translation — it never asserts a medical fact on its own.
